# 📄 ResumeScope

A smart resume analyzer built using **Python** and **Streamlit** that helps users evaluate their resumes for ATS compatibility.

---

## 🚀 Features

- 📄 Upload Resume (PDF)
- 📖 Extract Resume Text
- 📧 Detect Email Address
- 📱 Detect Phone Number
- 💻 Detect GitHub Profile
- 🔗 Detect LinkedIn Profile
- 🛠 Detect Technical Skills
- 📚 Resume Section Analysis
- 📊 Resume Scoring
- 💡 Personalized Suggestions

---

## 🛠 Tech Stack

- Python
- Streamlit
- Regex
- PDF Processing
- Git & GitHub
